リポジトリ

リポジトリの内容を以下に示します。

bin ディレクトリ
Makefile が生成した実行可能ファイルとメッセージ カタログを格納します。
docs ディレクトリ
リポジトリを説明するファイルを格納します。
gtk ディレクトリ
GTK ユーザー インターフェース テンプレートを格納します。
icons ディレクトリ
GTK アプリケーションが使用する画像を格納します。
include ディレクトリ
GTK アプリケーションを宣言するファイルを格納します。
obj ディレクトリ
Makefile が生成したオブジェクト ファイルを格納します。
src ディレクトリ
アプリケーションを実装するファイルを格納します。
text ディレクトリ
メッセージ カタログを格納します。

Viewer モジュール

Viewer About Dialog オブジェクト

バージョン情報ダイアログ ボックスを表します。 UI テンプレートからウィジェットを作成します。

Viewer Application クラス

GTK アプリケーションを表します。 ユーザーが選択した印刷設定を格納します。 ドキュメント ウィンドウを作成して表示します。

オブジェクトのプロパティを以下に示します。

Debug プロパティ
この値が TRUE である場合はウィンドウの設定を使用しません。 起動時に --debug オプションを指定してこのプロパティを TRUE にします。

Viewer Document インターフェース

オブジェクトがドキュメントを所有していることを表します。 ドキュメントを取得する方法を提供します。

Viewer Document Window クラス

アプリケーションが起動した際に表示されるウィンドウです。 ユーザーが開いた画像を所有します。 描画領域に画像を表示します。

Viewer Window Settings インターフェース

ウィンドウの設定を読み書きする方法を提供します。

このインターフェースが提供するメソッドを以下に示します。

Load メソッド
ウィンドウの設定を読み込んで適用します。
Save メソッド
ウィンドウの設定を書き込みます。

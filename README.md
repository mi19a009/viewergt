# ピクチャ ビューアー
GTK 版ピクチャ ビューアー。

## 仕様
- アプリケーションはファイルから開いた画像を表示できます。
- リポジトリのルート ディレクトリでアプリケーションをビルドできます。

## 設計
- GTK を使用してアプリケーションを作成します。
- Ubuntu を使用してアプリケーションをビルドします。

## 内容
| 場所 | 内容 |
| -------- | -------- |
| bin      | Makefile が生成した実行可能ファイルとメッセージ カタログを格納します。 |
| gtk      | GTK ユーザー インターフェース テンプレートを格納します。 |
| icons    | GTK アプリケーションが使用する画像を格納します。 |
| include  | GTK アプリケーションを宣言するファイルを格納します。 |
| obj      | Makefile が生成したオブジェクト ファイルを格納します。 |
| src      | アプリケーションを実装するファイルを格納します。 |
| text     | メッセージ カタログを格納します。 |

## 取付
``` sh
# アプリケーションをインストールします。
make
make install
# アプリケーションをアンインストールします。
make uninstall
```
